# University Management System

This project is a University Management System developed using PostgreSQL. It manages students, professors, courses, and enrollments through a relational database structure.
The database demonstrates key SQL concepts such as primary keys, foreign keys, joins, aggregate functions, subqueries, views, and window functions.

Key features:

* Student Management
* Professor Management
* Course Management
* Enrollment Tracking
* Grade Analysis

Analysis performed:

* Students by Department
* Average Grade by Course
* Top Performing Students
* Course Distribution by Professor
* Student Rankings

The project provides hands-on experience in database design, SQL query writing, and data analysis using PostgreSQL.
